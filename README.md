## § 00 · THE *Formation Lap*

</div>

> ### ◆ What am I looking at?
>
> **THE GRID** is a `single-file` · `zero-framework` · `fully-live` Formula 1 dashboard for the **2026 season**.
> No build step. No npm install. No dependencies. One `index.html` that turns your browser into the pit wall.
>
> - ◆ **Sign your name** — it greets you on the dashboard. Quiet, never loud.
> - ◆ **Pick your driver** — their *colour rides shotgun* across every screen you see.
> - ◆ **Live everything** — standings, countdowns, paddock intel, weather, tyre strategy.
> - ◆ **Real data** — straight from the same APIs the nerds use. Refreshed while you watch.

<br>

| | |
|:---:|:---|
| ⚡ | **LIVE POSITIONS UPDATE EVERY `30s`** |
| 🛰️ | **FEED REFRESH EVERY `10 MIN`** — `60s` during a live session |

## § 01 · The *Dashboard*

### ***every light on the wall, wired and working***

</div>

| ◆ SYSTEM | ▸ WHAT IT DOES |
|:---|:---|
| 🏁 **RACE HUB** | Next Grand Prix front-and-centre — circuit, lap record, pole history, dates, laps |
| ⏱️ **LIGHTS OUT IN…** | A live countdown ticking to Sunday, down to the *second* |
| 📅 **SEASON CALENDAR** | All **22 rounds** of 2026 with flags, circuits, dates & winner tags |
| 👑 **DRIVERS' CHAMPIONSHIP** | Top 10 live, gaps to the leader, points in mono |
| 🏆 **CONSTRUCTORS' CUP** | Every one of the **11 teams** — with title history baked in (`× 16 titles`…) |
| 🗞️ **PADDOCK INTEL** | Last race podium, top stories, fastest lap, championship math |
| 🌦️ **RACE CONDITIONS** | Air temp · track temp · humidity · rain — real samples, not forecasts |
| 🛞 **TYRE STRATEGY** | Soft / medium / hard / inters / wet — how the top finishers ran it |
| ⏳ **QUALIFYING** | Full Q1 → Q2 → Q3 classification with gaps, thousandths included |
| 🎴 **YOUR DRIVER CARD** | Recent form, standing, career wins & poles — shareable |
| 💾 **ONBOARDING** | Name + driver stored locally — the dashboard becomes *yours* |

## § 04 · Race-Day *Telemetry*

### ***where the numbers come from***

</div>

| ◆ SOURCE | ▸ FEEDS IT SUPPLIES | ▸ REFRESH |
|:---|:---|:-:|
| **[JOLPICA F1](https://github.com/jolpica/jolpica-f1)** *(Ergast successor)* | schedule · standings · results · qualifying · career numbers | `every 10 min` |
| **[OPENF1](https://openf1.org)** | air temp · track temp · humidity · rainfall · tyre strategy | `every 60 s` in session |
| **LOCAL CACHE** | per-driver career profiles | `cached 6 h` per code |

> ◆ **Why Jolpica?** — authoritative for results because it mirrors the *FIA classification*. Real samples per session, never forecasts.

## § 05 · The *Pit Wall*

### ***zero installs · zero builds · one file***

</div>

```bash
# roll the car out of the garage
git clone https://github.com/amansinghyadav4/The-Grid.git

# enter the pit lane
cd The-Grid

# ignition — open it in your browser
start index.html        # windows
open index.html         # macos
```

```
 THE-GRID/
 ├── ◆ index.html     ← the entire championship, in one file
 ├── ◆ logo.png       ← the crest
 └── ◆ README.md      ← you are here
```
